### 이슈
1. 자주 쓰는 동작 세 개에 단축키가 없어 매번 메뉴나 버튼을 눌러야 합니다.
   * ASIS: 와일드카드 새로고침은 Edit 메뉴, Run (Instant) 전환은 Run 버튼의 메뉴, 링크 숨기기는 캔버스 메뉴에서 합니다.
   * TOBE: `C`로 와일드카드 새로고침, `I`로 Run (Instant) 켜기(바로 실행)와 끄기, `L`로 링크 보이기/숨기기를 합니다.

### 원인 분석
1. 세 동작에 기본 단축키가 없고, Run (Instant) 전환은 단축키에 붙일 명령도 없습니다.

### 솔루션
1. 단축키 세 개를 팩의 기본 단축키로 등록했습니다.
   - `C`: Impact Pack의 `Impact: Refresh Wildcard` 명령.
   - `I`: 새 명령 `Toggle Run (Instant)`. 꺼져 있으면 Run (Instant)로 바꾸고 바로 한 번 실행하고, 켜져 있으면 일반 Run으로 돌립니다. 돌고 있는 작업은 끝까지 갑니다.
   - `L`: 기본 명령 `Toggle Link Visibility`.
   - `W`는 기본 단축키(워크플로 사이드바)와 겹쳐 팩 단축키로 등록되지 않아 `C`를 씁니다.
   - 세 키는 수정자 키 없이 쓰는 기본 단축키, 설치된 다른 팩의 단축키와 겹치지 않습니다.

### 대표 예제
